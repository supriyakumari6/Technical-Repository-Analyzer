# Technical-Repository-Analyzer
Building an AI-powered tool using LangChain and OpenAI API that analyzes GitHub repositories and flags the most complex
ones based on nesting depth, lines of code, and path generation – working towards helping developers quickly identify which
parts of a codebase need the most attention.
• Implementing a Streamlit web interface with automated error detection to reduce manual code review effort – targeting a 20+
hour reduction per review cycle upon completion
